# 인스타그램 게시물 템플릿

게시물을 만들어 줄 때 아래 형식을 그대로 채워서 준다. `[ ]` 안은 내용으로 바꾼다.

---

## 릴스 대본

```
🎬 릴스: [제목]
길이: [15~30]초 / 말투: [ ]

훅 후보
1) [ ]
2) [ ]
3) [ ]

| 시간 | 화면 (무엇을 찍나) | 화면 자막 | 말(내레이션) |
|---|---|---|---|
| 0~2초 | [결과물 / 표정 / 궁금증 장면] | [훅] | [ ] |
| 2~8초 | [ ] | [ ] | [ ] |
| 8~20초 | [ ] | [ ] | [ ] |
| 마지막 | [완성 / 반전] | [저장 유도 한 줄] | [ ] |

커버 문구: [5~10자]
배경음 분위기: [잔잔한 / 신나는 / 트렌디한] (앱에서 인기 음원 중 고르기)
```

## 캐러셀 (카드뉴스)

```
🖼 캐러셀: [제목] (총 [5~8]장)

1장 (표지): [큰 제목 — 훅]  /  작은 글씨: [부제]
2장: [문제 제기 또는 공감]
3장: [포인트 1]
4장: [포인트 2]
5장: [포인트 3]
...
마지막 장: [한 줄 요약] + "나중에 보려면 저장 🔖"
```

## 캡션

```
[첫 줄 훅 — 이 줄만 보이고 나머지는 "더 보기"에 숨겨진다]

[문단 1: 상황 / 공감 1~3줄]

[문단 2: 핵심 내용 1~3줄]

[문단 3: 내 생각이나 팁 1~2줄]

[질문 또는 행동 유도: 예) 여러분은 어떻게 하세요? 댓글로 알려주세요]

#[주제태그] #[주제태그] #[넓은태그] #[시리즈태그]
```

## 스토리 (3장 세트)

```
1장: [오늘 근황 / 게시물 예고] + 이모지 슬라이더 또는 투표 스티커
2장: [비하인드 사진·영상] + 질문 스티커 "[ ]"
3장: [새 게시물 공유] + "새 게시물 보러 가기 👆"
```

## 주간 계획표

```
| 요일 | 형식 | 필러 | 주제 | 훅 한 줄 | 준비물 |
|---|---|---|---|---|---|
| 월 | 릴스 | [ ] | [ ] | [ ] | [ ] |
| 수 | 캐러셀 | [ ] | [ ] | [ ] | [ ] |
| 금 | 릴스 | [ ] | [ ] | [ ] | [ ] |
| 매일(가능하면) | 스토리 | 일상 | [ ] | - | - |
```

---

## 훅 패턴 모음 (예시는 자취 요리 계정 기준)

- **숫자**: "5천원으로 3끼 해결하는 법"
- **질문**: "계란 아직도 이렇게 보관하세요?"
- **실수 고백**: "자취 1년 차가 제일 후회하는 주방템"
- **비교**: "편의점 도시락 vs 15분 집밥, 가격 비교해 봤어요"
- **결과 먼저**: (완성 사진부터 보여주고) "이게 전자레인지로 된다고?"
- **나만 몰랐던**: "나만 몰랐던 양파 안 맵게 써는 법"
- **시리즈**: "자취생 냉장고 털기 #3"
