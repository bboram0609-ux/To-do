- 속지 종류: 줄노트, 모눈, 도트, 무지, 투두 리스트, 데일리, 위클리, 먼슬리, 해빗 트래커, 코넬 노트, 독서 기록, 가계부
- 용지: A4, A5, B5, A6, HB 6공, Letter (세로/가로)
- 여백, 바인딩 여백(양면 인쇄 시 홀짝 페이지 자동 전환), 선 색상·굵기, 칸 간격, 제목, 날짜 칸, 페이지 수 설정
