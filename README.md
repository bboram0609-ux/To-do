# 속지 메이커

다이어리·노트 속지를 만들고, 바인더 펀칭 위치를 표시하고, 스티커·마스킹 테이프·글자·사진으로 꾸며서 PDF로 받는 웹사이트입니다. `index.html` 파일 하나로 동작합니다.

- **속지 12종**: 줄노트, 모눈, 도트, 무지, 투두, 데일리, 위클리, 먼슬리, 해빗 트래커, 코넬 노트, 독서 기록, 가계부
- **용지**: A4, B5, A5, 바이블, A6, 미니6, Letter
- **펀칭**: 2공, 4공, 6공(A5·바이블·미니6), 다공 루즈리프(9.5mm). 왼쪽/위쪽, 양면 인쇄 시 짝수 쪽 반대편. 구멍 자리만큼 여백이 자동으로 넓어짐
- **꾸미기**: 스티커, 마스킹 테이프, 이모지, 손글씨 글꼴 글자, 사진. 드래그로 이동, 모서리로 크기 조절, 회전·투명도·색, 모든 페이지/이 페이지만 적용
- **출력**: 실제 크기(mm) PDF 다운로드, 인쇄

작업 내용은 브라우저에 자동 저장됩니다.
